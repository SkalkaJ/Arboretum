## K čemu to je?
V přírodních vědách pro ukázání, že se model chová jinak, než pozorování
=> dá se vymyslet nový, přesnější model, dokud se nebude shodovat
*vyvracení hypotéz*

## Co se modeluje
- jev
- chování
- vlastnost
- *= všechno vpodsatě to samé*
- nelze modelovat objekt (kontext)

## Jak se modeluje
- otázka do jaké hloubky - prvky podsystémů,...
- Ocamovat břitva - musí se najít ten *jejednodušší model*, který vystihuje jev (snadno vyyvrátitelný)
- modelování pomocí *černých skříněk* - když známe jen vstupy a výstupy, vnitřek nás nezajímá (dělba práce mezi obory)
- **Tři typy otázek**
	- Explorace = výstupy okrajových prvků, objevení nových jevů
	- Mechanizmus jevu = zkoumání systému za jevem, struktury prvků a podsystémů, odvození, že se bude model chovat, tak jak víme, že se chová
	- Účel jevu = něco se děje, *proto aby* se něco stalo (systém je součástí systému svého okolí)

## Redukcionismus
- výčitka vědcům, že věc neberou od prvočinitelů a předpokládají nějaký mechanismus fungování
- Občas je ale potřeba vysvětlovat seshora dolů
- Biologie se nedá redukovat na chemii (např. jak se zformoval genetický kód, je to náhoda)
